Política de Privacidad

Última actualización: 29 de septiembre de 2026

Esta Política de Privacidad explica qué información puede procesar Zyvora cuando interactúas con el bot de Discord.

1. Responsable

El servicio Zyvora es administrado bajo el nombre de Zyvora.

Para consultas relacionadas con privacidad puedes contactar mediante:

zyvora.bot@gmail.com

2. Información que puede procesarse

Dependiendo de las funciones utilizadas y de la configuración del servidor, Zyvora puede procesar información proporcionada por Discord o generada mediante la interacción con el bot.

  • ID de usuario de Discord.
  • ID del servidor de Discord.
  • ID de canales, roles o mensajes cuando sea necesario para una función determinada.
  • Nombre de usuario o etiqueta de Discord cuando sea necesaria para mostrar información.
  • Información relacionada con la economía virtual de Zyvora.
  • Información relacionada con trabajos, progreso, estadísticas, propiedades, inversiones y préstamos virtuales.
  • Información relacionada con acciones de moderación realizadas mediante Zyvora cuando corresponda.

3. Datos de economía virtual

Cuando utilizas las funciones de economía, Zyvora puede almacenar información como:

  • Dinero virtual disponible.
  • Saldo bancario virtual.
  • Historial de transacciones.
  • Trabajos y progreso.
  • Historial crediticio virtual.
  • Propiedades y otros activos virtuales.
  • Inversiones y préstamos virtuales.
