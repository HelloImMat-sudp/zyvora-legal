Condiciones del Servicio

Última actualización: 29 de septiembre de 2026

Estas Condiciones del Servicio regulan el uso del bot de Discord Zyvora.

Al utilizar Zyvora, añadirlo a un servidor o interactuar con sus funciones, aceptas estas condiciones.

1. Sobre Zyvora

Zyvora es un bot multifunción para Discord que proporciona diferentes herramientas para comunidades y servidores.

Sus funciones pueden incluir, entre otras, herramientas de moderación, administración, economía virtual, trabajos, inversiones, propiedades, préstamos, estadísticas y sistemas de entretenimiento.

2. Requisitos de uso

Para utilizar Zyvora debes cumplir con las condiciones de uso de Discord y con las normas aplicables a tu servidor.

Los administradores de cada servidor son responsables de configurar y utilizar las funciones de Zyvora de acuerdo con las normas de su comunidad.

3. Uso permitido

Zyvora debe utilizarse únicamente para fines legales y de acuerdo con estas condiciones.

No está permitido utilizar Zyvora para:

  • Intentar interferir, sobrecargar o interrumpir el funcionamiento del bot.
  • Explotar errores o vulnerabilidades de manera intencional.
  • Utilizar automatizaciones, scripts o herramientas para abusar de las funciones del bot.
  • Intentar obtener acceso no autorizado a sistemas o datos.
  • Utilizar el bot para actividades ilegales.

4. Economía virtual

Zyvora puede proporcionar sistemas de economía virtual que incluyan dinero virtual, bancos, trabajos, propiedades, inversiones, préstamos, patrimonio y otros elementos similares.

Todos los elementos de la economía de Zyvora son virtuales y no representan dinero real, depósitos bancarios, inversiones financieras reales ni instrumentos financieros.

El dinero virtual y los activos digitales dentro de Zyvora no tienen valor monetario real y no pueden convertirse en dinero real a través de Zyvora.

5. Rasca y Gana y funciones de azar

Zyvora puede incluir sistemas de entretenimiento basados en probabilidades, como Rasca y Gana u otras funciones similares.

Estas funciones utilizan únicamente elementos de la economía virtual de Zyvora y no representan apuestas con dinero real.

6. Datos económicos

Zyvora puede almacenar información relacionada con la actividad económica virtual de un usuario, incluyendo balances, trabajos, transacciones, inversiones, préstamos, patrimonio, historial económico y progreso.

Esta información se utiliza para proporcionar y mantener las funciones de economía del bot.

7. Moderación

Zyvora puede proporcionar herramientas de moderación como expulsiones, prohibiciones, silenciamientos, eliminación de mensajes y otras acciones administrativas.

Las decisiones tomadas mediante las herramientas de moderación corresponden a los administradores y moderadores del servidor que las utilizan.

Zyvora no es responsable de las decisiones administrativas tomadas por los usuarios o administradores de un servidor.

8. Disponibilidad

Zyvora se proporciona como un servicio que puede cambiar, actualizar, suspenderse temporalmente o dejar de estar disponible.

Las funciones pueden modificarse, añadirse o eliminarse en cualquier momento para mejorar el servicio, corregir errores o realizar tareas de mantenimiento.

9. Reinicios y pérdida de datos

Aunque se toman medidas razonables para mantener los datos del servicio, no se garantiza que la información almacenada esté disponible de forma permanente.

Los errores técnicos, fallos del servicio, mantenimiento, corrupción de datos u otras circunstancias pueden provocar pérdida o modificación de datos.

10. Suspensión del acceso

Zyvora puede restringir o suspender el acceso de un usuario o servidor cuando exista un uso abusivo, malicioso o contrario a estas condiciones.

11. Cambios en estas condiciones

Estas condiciones pueden actualizarse cuando sea necesario para reflejar cambios en Zyvora, sus funciones o requisitos legales.

La fecha de la última actualización aparecerá al principio de esta página.

12. Contacto

Si tienes preguntas relacionadas con estas condiciones, puedes contactar con Zyvora mediante:

zyvora.bot@gmail.com

Importante: Zyvora es un bot independiente de Discord. Discord no es responsable del funcionamiento de Zyvora ni de los contenidos de estas condiciones.
